# Convolutional Neural Network

Convolutional Neural Network, or CNN, is a neural network commonly used to process images and other grid-like data.

Convolutional layers apply learned filters to local regions of the input. These filters can detect patterns such as edges, textures, and shapes. The same filter weights are reused across different positions.

Activation functions introduce nonlinearity. Pooling layers can reduce the size of feature maps, although not every CNN uses pooling. Later layers combine learned features to make predictions, such as identifying the object in an image.
